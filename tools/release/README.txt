FlameKit {version} for Enshrouded, by Ninechars
================================================

INSTALL (also to update from an older FlameKit, such as 0.14)
1. Extract this zip into a folder first (right-click > Extract All...). It does not work from inside the zip.
2. Close Enshrouded.
3. Double-click install.cmd. It finds the game through Steam and copies everything in.
   (Game somewhere Steam does not know? Drag the game folder, the one with enshrouded.exe, onto install.cmd.)
   An older FlameKit is removed first, including 0.14's separate minimap (flamekit_map). Your junk list, window
   places and settings are kept.
4. Start the game in BORDERLESS or WINDOWED mode. FlameKit's windows do not show in exclusive fullscreen.

From now on FlameKit updates itself, and the Enshrouded Modding Framework (EMF) it runs on too: when a new version has
downloaded, it tells you, and the next game start uses it. (F4 > About: "Keep EMF updated" switches EMF's part off.)

USE
- F4 opens the FlameKit Menu (Auto Junk List, Minimap, Experimental, Building, Settings, Windows, About and more).
- F5 PvP Leaderboard, F6 Experimental window, F7 Party window, F8 Messages window, F10 minimap on or off.
- Hold Right Alt to use the mouse in FlameKit's windows (or set it to a single press in F4 > Windows).
- F4 > About shows the full guide, the Change Log, and which FlameKit and EMF versions you run.

GOOD TO KNOW
- The server needs FlameKit too for most features (PvP, fast travel, Free build, the experimental options, the
  leaderboard). Ask the server's owner to install the same version.
- Windows may ask about the unsigned files the first time: More info > Run anyway.
- After a game update some parts can stop working until FlameKit is updated. The rest keeps running.
- uninstall.cmd removes EMF and FlameKit again.

This package contains EMF {emf_version} (the Enshrouded Modding Framework, MIT licence: EMF-LICENSE.txt, licenses\) with
its Lua host, FlameKit and FlameKit Native. EMF-README.txt is EMF's own readme.
